# seb5594 brand

Original logo designed for this repository using the built-in Imagegen tool.
The full-resolution PNG is `seb5594.png`; the integration's `brand/` directory
contains 256 px and 512 px PNG variants with the original alpha channel retained.
The outside of the rounded emblem is transparent. The inner field uses three
horizontal black-red-gold bands. Sky-blue lettering and connectors sit above
lighter slate-blue digits. A continuous silver-white contour around the lettering,
connectors and circular nodes separates the foreground from the flag at icon size.
